# Python To-Do List

A Python Tkinter To-Do List application for managing daily tasks.

## Features

- User Login
- Add Tasks
- View Tasks
- Update Tasks
- Delete Tasks
- Mark Tasks as Completed
- Search Tasks
- Priority Management
- Due Date Management
- Dashboard Statistics
- Save Tasks

## Technologies Used

- Python
- Tkinter
- JSON

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

```bash
python todo.py
